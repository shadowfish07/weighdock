# WeighDock 介绍和隐私政策源文件

`index.html`、`privacy/index.html`、`styles.css`、`icon.svg` 是无脚本、无追踪器、无第三方字体的静态页面，公开联系邮箱为 public@zqydev.me，项目源码见 [https://github.com/shadowfish07/weighdock](https://github.com/shadowfish07/weighdock)。页面不处理称重或凭据。

本目录的隐私政策是与 0.3.1 对齐的**本地草稿**，外部已部署版本不会随源码修改更新。首次网站部署与此后应用变更之间可能存在差异，维护者应审阅政策后单独发布；本次源码准备未部署或改 DNS。

可直接打开 HTML 预览。`python3 website/prepare.py` 仅在本机生成四项资产到 `dist/` 和 ZIP，移除草稿横幅与 noindex，拒绝占位符及非预期文件；不会联网或部署。只可发布这四项经过审阅的资产，不应上传整个仓库。

文案依据实际源码，区分本地 JSON、偏好设置、Keychain 与 Google Health。没有真实历史删除 UI 或云端删除 API，体重偏差检测也不是多用户身份识别。网站托管方的必要请求信息不等于应用上传健康数据。

# WeighDock 的数据与隐私

本页说明当前应用实际处理的数据，不是设备厂商或 Google 的政策。应用没有开发者健康数据中转、广告或遥测服务。

## 本机保存

- 原始设备 MAC、BLE Bind Key、OAuth 客户端和 Google 授权状态保存在 macOS Keychain。
- 出生年份、身高、公式性别、过滤阈值及接收／同步设置保存在本机偏好设置。资料独立修改，不重算旧记录。
- 测量历史为本地 JSON，包括时间和 UTC 偏移、体重、可用双频阻抗、有效体脂及算法版本、去重 ID、过滤元数据与各指标同步进度。目录／文件创建权限为 0700／0600，采用原子写入；没有应用层加密。
- 心率可能短暂解析，但不保存或上传。原始广播只短暂参与认证解码和内存去重，不保存为原始数据包。
- 数据位置与兼容标识见[兼容性说明](Compatibility.md)。没有自动过期清理。

## Google Health 同步

OAuth 连接与开启同步分别确认。开启后会处理本机尚未完成的有效真实记录，后续可按原设置恢复接收和同步。后台恢复未完成或失败时保持明确状态，不将未知连接当作已就绪。

唯一请求的 scope 为：

```
https://www.googleapis.com/auth/googlehealth.health_metrics_and_measurements.writeonly
```

应用直接向 Google 写入体重（克）或有效体脂（百分比）、测量时间／UTC 偏移和稳定记录名。阻抗、个人资料、MAC 和 Bind Key 不在健康数据请求中；不请求读取健康历史、账号邮箱或设备列表。客户端信息和令牌仅按 OAuth 协议与 Google 交换。配置步骤见[Google Health 指南](GoogleHealthSetup.md)。

体重和体脂分别保留进度。断网或可重试错误会退避重试；授权失败暂停同步，不明确的结果保留待检查。模拟记录及体重过滤项禁止上传。暂停阻止后续请求，在途请求可能完成。

## 过滤、估算与多人使用

体重变化检测默认10%，可关闭或设整数1–50%。超过阈值的真实称重保存在记录中标为“体重偏差较大，未同步”，不生成上传项、不更新比较基线；更改设置不补传旧过滤项。

目前一台秤对应一份资料，体重过滤不是身份识别。其他人的称重仍可能记入同一资料。体脂由公式结合阻抗和资料估算，缺输入只保留体重；不能保证与米家一致。来源和局限见[算法说明](MiHomeCompatibilityStudy.md)。

## 暂停、撤销与删除

- 关闭窗口后菜单栏进程仍运行。可分别暂停接收和同步；退出应用会停止进程中的接收／重试。Mac睡眠无法收数，未收到的广播不能补回；锁屏与睡眠不同。
- “断开连接”暂停同步并移除本机 Google 授权，保留记录和已单独保存的客户端配置；旧版仅随授权保存的客户端可能需重新导入。Google侧撤销需在[账号第三方连接](https://myaccount.google.com/connections)操作。
- 当前没有真实历史删除UI、设备凭据删除按钮或云端删除API。更换设备不删历史。若自行清理本地JSON，须先退出并备份；这同时清除本地队列进度。卸载或清本机数据不删除已上传记录，云端数据通过Google Health管理。
- 应用不输出健康值、MAC、密钥、原始广播、令牌或服务错误正文，依赖详细网络日志默认关闭。请勿公开真实记录、凭据、未经检查的截图或系统诊断；漏洞渠道见[SECURITY](../SECURITY.md)。

## 公式、单位与两层夹限

令 H 为 cm，W 为 kg，A 为明确传入的年龄（年），Z 为 50 kHz 阻抗（Ω）：

`raw% = 100 × (cH×H + cW×W + cA×A + cZ×Z + C) / W`

| 公式性别 | cH | cW | cA | cZ | C |
|---|---:|---:|---:|---:|---:|
| 男 | -0.3315 | 0.6216 | 0.0183 | 0.0085 | 22.554 |
| 女 | -0.3332 | 0.7509 | 0.0196 | 0.0072 | 22.7193 |

发布实现先 `n = int(raw% × 100)`（向零截断），再按 Python 的整除／余数语义舍入到 0.1，最后夹到 **3–55%**。它不同于直接使用 Swift 默认的四舍五入；Swift 实现保留了负数和边界的行为。

`LBM = W × (1 − 已舍入并夹限的体脂 / 100)`，此处不额外舍入去脂体重。例如已发布配对夹具的计算值为 60.2446 kg，与显示值 60.2 kg 在其原测试容差内。BMR 后续才会把 LBM 舍入到 0.1 kg，本轮未移植 BMR。

重要差异：BodyMiScale 的外层 `get_fat_percentage` 又调用 `check_value_constraints(..., 5, 75)`，因此外层指标在低端实际为 **5–55%**；但其 LBM 仍使用公式层 3–55%。模块显式返回这两种体脂结果，不擅自合并。公开下限夹具为公式 3%、外层 5%，并测试 LBM 采用前者。

双频适配层要求两项正的有限阻抗，用 `max(A,B)` 识别 Z50、`min(A,B)` 识别 Z250，避免 BLE 集成命名相反。体脂／LBM 的公式只读 Z50；Z250 在这一子集中只用于双频输入完整性及排序。BLE 原始整数要先除以 10 换成 Ω，不能把 6000 原样当 600 Ω 使用。

上游年龄按完整出生日期计算周岁；本模块直接要求 ageYears，不从出生年份估算。当前生产默认算法只有年份差。将来同次对照必须使用与米家相同的年龄、身高和公式性别。

Swift 接口明确拒绝非正数、NaN、无穷和数值溢出，不以 0% 伪装成功；未额外加上默认算法的成人／BMI／阻抗范围和接触门槛。因此这些输入域检查不构成临床适用范围，也不表示儿童算法已获验证。

## 阻抗平滑及历史依赖

发布文件明确把历史阻抗平滑列为已知缺口：使用原始输入，**没有平滑实现或历史状态**。本模块保持相同行为，测试 A→B→A 调用不会改变 A 的结果，没有偷偷读取历史记录。

issue 讨论曾给出以下候选规则（dbfp 为体脂变化的绝对百分点，dt 为距之前测量的时间）：

| 讨论条件 | 描述的阻抗选择 |
|---|---|
| dbfp < 3.6，dt ≤ 10 分钟 | 旧阻抗 |
| dbfp < 3.6，10–30 分钟 | 0.8×旧 + 0.2×新 |
| dbfp < 3.6，dt > 30 分钟 | 两者平均 |
| 3.6 ≤ dbfp < 6.1 | 两者平均 |
| dbfp ≥ 6.1 | 新阻抗 |

这些讨论未合并到该发布算法，旧值究竟用先前 raw 还是 smoothed、先前体脂如何计算也曾被追问；后续评论对长间隔还给出了不触发平滑的观察。不能把该表包装成已验证实现。本轮不移植讨论伪代码。要追求连续多次称重一致，仍缺完整的对应用户历史阻抗、时序、最终平滑规则及同次米家观测。

## 舍入与浮点

采用 Double 匹配 Python 发布版的 float 运算顺序，不调用 FMA。公开的 23.349→23.3、23.35→23.4、23.3499→23.3 以及负数舍入边界通过。

除公开夹具外，自写 Swift 合成算术扫查共 **11,428** 次，含 10,000 次常规输入和 1,428 次舍入切点附近输入。用 Float32 重算系数和中间值时，754 次最终一位小数不同，最大 **0.1 个百分点**。这刻意集中在切点附近，不是误差概率或临床样本，也不是原作者 30,000 次 QEMU 检验。不能由 Python/Swift 一致推导出对原 MCU 的逐位一致。

## 进入本人同次验证前还缺什么

需要用户明确同意后，在本机准备一次性离线输入／对照方式，以同一测量的体重、两个新鲜阻抗和与米家一致的资料比较已显示体脂。当前模块没有提供该生产输入 UI，不应为了验证要求用户把密钥或完整健康历史发到聊天。

首次可优先选择较长间隔后的称重，同时记录时序条件；如需解释相邻称重差异，还要补齐可信平滑实现与所需历史上下文。离线阶段不含默认切换、历史重算或真实上传；后续接入仅授权了新测量默认切换，没有授权历史重算或测试上传。兼容性验证不能证明“中国人最准”或替代健康评估。
